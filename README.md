# Нейро-сотрудник для управляющей организации

Помощник для УК и ТСЖ: читает документы жителей, достаёт поля правилами, сверяет сроки и коды
с законами и справочниками, отвечает на вопросы по базе знаний и собирает проект акта.

Приложение сделано на **Streamlit** — это и есть пользовательский интерфейс (frontend):
загрузил документ, увидел результат, получил выписку. Colab остаётся средой разработки,
а продукт запускается как обычное веб-приложение.

## Что умеет

| Экран | Что делает |
|---|---|
| **Документ** | загрузить PDF или фото → определить вид документа → вытащить поля правилами → показать, **куда документ идёт в учёте** и чего в нём не хватает → отметить значения рамками значимости (**ПДн · секрет · оплата · API-ключ · идентификатор**) → расшифровать **QR и штрих-коды** → сверить коды (ИНН, СНИЛС, ОГРН — арифметикой; КПП, БИК, ОКУД — форматом и официальным классификатором) → показать оригинал рядом с полями → скачать черновик акта |
| **Вопрос по законам** | ответ по базе знаний со ссылкой на пункт и **проверкой кодом**: есть ли ссылка, нет ли чисел вне базы |
| **Сокращения** | библиотека (54 записи) с подсказками: полное название, латиница, как читается, источник. Можно добавить своё значение — прежние не затираются |
| **О приложении** | что умеет, чего не умеет, из каких модулей состоит |

## Модули (английские имена, как требует стандарт разработки)

```
app.py           интерфейс Streamlit
core.py          база знаний, поиск, ответ модели, поля документа, значимость, акт
recognition.py   текст с фото и скана (Tesseract, 4 поворота)
codes.py         QR, штрих-коды, сверка кодов по классификаторам
glossary.py      библиотека сокращений с вариантами значений
data/            knowledge_base.json · okud_codes.json · abbreviations.json
```

Правило дома: **модель предлагает — правило решает**. Модель читает и формулирует,
все числа, сроки, проверки и сборку акта делает код.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для ответов большой модели нужен локальный движок **Ollama** (`http://127.0.0.1:11434`)
с моделями `qwen2.5:3b` и `bge-m3`. Без движка приложение работает: читает документы, ищет
по базе, показывает найденные пункты — только формулировку ответа не даёт.

Для чтения фото нужен **Tesseract 5** (Windows: `C:\Program Files\Tesseract-OCR\tesseract.exe`).
В облаке его нет — там работает текстовый слой PDF.

## Чего в этой версии нет

Годовых и месячных отчётов · сводки «что просрочено» · распознавания рукописного текста ·
голосового ввода. Это следующий этап работы.

## Данные

- `data/knowledge_base.json` — 16 пунктов из 8 открытых актов жилищного права.
- `data/okud_codes.json` — 2 030 кодов форм по ОК 011-93 (ред. от 15.07.2026).
- `data/abbreviations.json` — 54 сокращения (ЖКХ, деньги, чеки, IT и форматы файлов).

Персональные данные не покидают компьютер: всё считается локально. Значения с метками
ПДн, секрет, оплата, API-ключ и идентификатор помечаются цветом и могут быть заменены
маской в акте перед выгрузкой (152-ФЗ, ст. 3, п. 9).
